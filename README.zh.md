这个[Obsidian](https://obsidian.md/)插件能让用户直接在笔记中进行 API 请求，并在代码块中显示响应。

## 🔒 安全性

本插件实现了全面的安全措施，包括：
- URL、路径和用户数据的输入验证
- 通过 HTML 清理防止 XSS 攻击
- 防止目录遍历攻击
- 安全的 JSONPath 表达式评估

## 🚀 安装

该插件可以从 Obsidian 内部安装。

### Obsidian 社区插件浏览器

- 转到 `设置` -> `社区插件`
- 确保 `受限模式` 已 **关闭**
- 点击 `浏览`
- 搜索 `APIRequest`
- 点击 `安装`，然后点击 `启用`
